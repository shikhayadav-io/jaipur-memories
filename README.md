# 🏰 Jaipur Memories — Shared Trip Photo Gallery

*A few days away, forever close.*

**Jaipur Memories** is a lightweight, full-stack shared photo gallery web application built to preserve and relive our team trip memories from Jaipur (CodeWars 1.0 Hackathon, 2026).

---

## ✨ Key Features

- **User Authentication:** Secure session-based login for team members.
- **Role-Based Permissions:** Controlled upload access so authorized members can add new trip photos safely.
- **Responsive Masonry Gallery:** Automatically reads and displays trip photos in a clean, Pink City-inspired aesthetic grid.
- **Lightbox Preview & Download:** Click any postcard/photo to view in full resolution and download memories anytime.

---

## 🛠️ Tech Stack

- **Backend:** Python, FastAPI, Jinja2
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Data & Storage:** JSON-based user access control & local static media storage
